<h1>UI</h1>

The <b>UI.png</b> file is the design.

<h3>Notes on the design</h3>

<h4>Tags</h4>

- The upmost tag on the tags list will always be "untagged" if there are untagged files present.
- Tags can be renamed or deleted by the icons to the right of them. There will be pop-ups for both.
- When clicked on a tag in the "Tags" section, the tag will move to the bottom section meaning the tag is selected and the files on the right will be updated accordingly. When clicked on a tag in the bottom section, the tag will be unselected and it will move to the upper section and the files will be updated once again.

<h4>Files</h4>

- To tag a file, click the icon to the right of it. A pop-up will appear and tags will be added and removed in a similar fashion to the Tags section.
- When clicked on a file, it will start playing. The rectangle at the bottom will be the audio control. The audio file will be served by the backend to the frontend via http.

<h4>Create Playlist</h4>

- When creating a playlist, one or multiple tags and the amount can be selected. When multiple tags are selected, only the files having the selected tags will be selected. The Add button will add the selection to the pool. Selecting tags will work in a similar fashion to the Tags section. Create button will create a shuffled playlist.
