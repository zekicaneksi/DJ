<h1>DJ - Backend</h1>

<h3>Technologies</h3>

- Go
- SQLite

<h3>Environment Variables</h3>

```
DJ_BACKEND_PORT --- The backend port
```

<h2>Development</h2>

<h3>Test</h3>

```
go clean -testcache && go test -v .
```

<h3>Run</h3>

```
go run .
```

<h2>Build</h2>

To create the executable

```
go build .
```
